# Орбита — научная редакция СНО

Веб-приложение для подготовки постов студенческого научного общества. Python / FastAPI, SQLite, обычные HTML/CSS/JS. Без сборки фронтенда и внешней базы данных.

## Документация

- [Пошаговая инструкция: установка, ИИ, первый пост и расписание](docs/INSTRUCTIONS.md).
- [Почему выбран GPT-5.4 mini: сравнение, стоимость и границы проверки](docs/AI_MODEL.md).

## Быстрый запуск

Требуется Python 3.11+ (проверено на 3.14).

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000 и создайте аккаунт на вкладке «Регистрация». Готовых пользовательских паролей в проекте нет.

## Что работает

- Регистрация, вход, выход и личная история; пароли хранятся с scrypt, сессии — в HttpOnly cookie, в базе только хеши токенов.
- Еженедельный пост, по умолчанию в понедельник в 10:00 по Москве, за предыдущие 7 полных календарных дней. День и время можно изменить, расписание — отключить.
- Кнопка «Создать пост», быстрые периоды 7/30 дней и собственные начальная/конечная даты. Границы включены, фильтр использует **дату публикации** по Москве; будущее и периоды более года отклоняются.
- Два скачиваемых вложения в личном диалоге: `post.txt` (UTF-8 BOM, удобно для Windows) и `photos.zip` (JPEG-фотографии из источников, квадратная обложка 1200×1200 и сведения об источниках/правах).
- История во вкладке «Мои материалы»; завершение задания появляется автоматически. Вкладку можно закрывать.
- Выбор источников, тематик, количества новостей (1–5), имени сообщества, правил и образцов текста, цвета обложки.
- Реальное чтение RSS [Naked Science](https://naked-science.ru/allrss) и [Элементов](https://elementy.ru/rss/news) каждый час и перед генерацией. Дедупликация по ссылке, отбор разных тематик/источников, сохранение архива в SQLite.

## ИИ и стиль ВК

Без ключа приложение **работает в режиме дайджеста**: собирает заголовки и аннотации из источников в текст с датами, ссылками, вопросом и хештегами. Это не авторская ИИ-переработка; правила и образцы текста в этом режиме не применяются. Цвет обложки применяется всегда.

Выбран **GPT-5.4 mini** с фиксированной версией и небольшим бюджетом рассуждения; [обоснование и стоимость](docs/AI_MODEL.md). Реальное качество на стиле сообщества предстоит проверить после получения образцов и API-ключа.

Для ИИ-редактуры задайте в `.env`:

```dotenv
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-5.4-mini-2026-03-17
OPENAI_REASONING_EFFORT=low
```

Затем перезапустите сервер. Для старых моделей без reasoning оставьте `OPENAI_REASONING_EFFORT=` пустым. До подключения проверьте [доступность в вашей стране](https://developers.openai.com/api/docs/supported-countries). Используется [OpenAI Responses API](https://developers.openai.com/api/reference/cli/resources/responses/methods/create). Название модели настраивается; нужен доступ к ней в вашем API-аккаунте. Запросы расходуют баланс провайдера. Ключ остаётся на сервере. В API отправляются только выбранные новости, название общества и настройки/образцы стиля; email и пароли не отправляются. Запрос использует `store=false`, отключая сохранение ответа в истории Responses. При ошибке ИИ сохраняется обычный дайджест с явным уведомлением.

**Ссылка на ВК ещё не предоставлена.** Поле для неё уже есть, но сохранение ссылки не запускает чтение стены. Анализ конкретных текстов и фотографий, а также точное воспроизведение оформления остаются следующей настройкой после получения ссылки. Приложение не заявляет, что проанализировало сообщество. Пока используются нейтральная обложка, настраиваемый цвет и, при подключённом ИИ, текстовые образцы.

## Ограничения источников и изображений

RSS содержит ограниченный набор последних записей. Приложение постепенно накапливает архив; произвольный прошлый период не гарантирует наличие всех публикаций. Доступные даты и последнее чтение видны на странице источников. Если ничего не найдено, в диалог приходит объяснение, вымышленные новости не генерируются.

Автоматический отбор использует категории по ключевым словам и разнообразие тем, не научную экспертную оценку. Проверяйте исходные публикации перед размещением. Фотографии берутся из RSS, их лицензии не считаются автоматически разрешающими перепубликацию. В архиве `sources-and-credits.txt` есть ссылки и доступные сведения об авторах. Если фото не удалось скачать, сохраняется графическая обложка и явное сообщение об отсутствии фотографий.

## Пользователи

По умолчанию доступна самостоятельная регистрация. Когда будет список пользователей, можно ограничить её email-адресами:

```dotenv
ALLOWED_EMAILS=student1@university.ru,student2@university.ru
```

Ограничение относится к новым регистрациям; существующие аккаунты не удаляются. Email не подтверждается почтой: allowlist не заменяет проверку владения адресом. Отправки писем и восстановления пароля пока нет.

## Постоянная работа

Сервер должен оставаться запущенным. Открытая вкладка не требуется. Для круглосуточной работы перенесите приложение на сервер. Запускайте **один процесс / один Uvicorn worker**: внутри него работает поток очереди и сборщик RSS. Несколько Uvicorn workers/reload для постоянной эксплуатации не поддерживаются. Задания и расписание хранятся на диске. После перезапуска незавершённые задания возвращаются в очередь; пропущенное расписание выполняется один раз за последние 7 полных дней, затем назначается следующая дата. Для каждого аккаунта допускается одна активная генерация и до 10 запусков за час.

Для Docker:

```sh
docker compose up -d --build
```

Контейнер перезапускается автоматически и хранит данные в именованном томе `sno-data`. По умолчанию порт доступен только локально. Для внешнего доступа настройте HTTPS reverse proxy и `COOKIE_SECURE=true`. При работе за proxy лимит входа по IP применяется к адресу proxy; дополнительно действует лимит по email. Для более высокой нагрузки потребуется отдельный обработчик очереди.

База и файлы находятся в `data/` (или `DATA_DIR`). Не добавляйте их в Git. Для резервной копии локального запуска остановите сервер и скопируйте каталог `data/` целиком. В Docker сохраняйте именованный том. Для Linux контейнер устанавливает DejaVu Sans для кириллицы на обложках; для иной среды можно задать `FONT_PATH`.

## Проверка

```sh
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
node --check static/app.js
```

Тесты выполняются с временной базой без сети и API-ключа: авторизация и изоляция файлов, генерация TXT/ZIP, валидация, межсайтовые запросы, фильтрация по Москве, расписание без дублей, восстановление очереди после перезапуска, ошибки источников и отсутствие фотографий.

Для дополнительной проверки интерфейса:

```sh
.venv/bin/pip install playwright
.venv/bin/python -m playwright install chromium
.venv/bin/python tests/browser_smoke.py
```

Этот сценарий сам запускает отдельный тестовый сервер с временной базой и проверяет регистрацию, настройки, реальную генерацию и скачивание файлов. Нужен доступ к RSS. Скриншоты сохраняются в `data/qa/`.
