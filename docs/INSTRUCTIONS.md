# Инструкция: от скачивания до первого поста

## 1. Скачать проект

```sh
git clone https://github.com/GnomikNaPony/mini_sno.git
cd mini_sno
```

Если папка уже есть, работайте в ней. Для получения последующих обновлений используйте `git pull --ff-only` при отсутствии незакоммиченных изменений.

## 2. Запустить

Выберите один способ.

### macOS / Linux, Python 3.11+

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000 --workers 1 --no-proxy-headers
```

Оставьте терминал работающим. Откройте **http://127.0.0.1:8000**. Остановка сервера — `Ctrl+C`. Для повторного запуска достаточно последней команды.

На Linux для кириллических обложек нужен DejaVu Sans. В Debian/Ubuntu: `sudo apt-get install fonts-dejavu-core`. В Docker он устанавливается автоматически.

### Windows, PowerShell

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Добавьте в `.env` путь к установленному шрифту с кириллицей:

```dotenv
FONT_PATH=C:/Windows/Fonts/arial.ttf
```

Запустите:

```powershell
.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 --workers 1 --no-proxy-headers
```

Windows-команды приведены как инструкция; автоматические проверки проекта выполнены на macOS.

### Docker Compose

Нужен установленный Docker с поддержкой Compose. Из корня проекта:

```sh
cp .env.example .env
docker compose up -d --build
```

Проверить запуск: `docker compose ps`. Посмотреть сообщения: `docker compose logs --tail=100 app`. Остановить: `docker compose down`.

Для обновления кода выполните `git pull --ff-only`, затем `docker compose up -d --build`. Данные остаются в томе `sno-data`. Не используйте `docker compose down -v`, если хотите сохранить аккаунты и историю. Контейнерный запуск описан, но сборка контейнера не входит в проведённую локальную проверку.

Если порт 8000 занят, остановите предыдущий экземпляр приложения. Для другого порта в Python поменяйте `--port`, в Compose — левое число в привязке порта.

## 3. Подключить ИИ-редактора

Без этого шага приложение создаёт дайджест из заголовков и аннотаций. Для авторской переработки:

1. Проверьте доступность API для вашей страны и аккаунта: подробности в [обосновании выбора модели](AI_MODEL.md#доступность).
2. Создайте ключ в [API-платформе OpenAI](https://platform.openai.com/api-keys) и настройте оплату в кабинете.
3. Откройте локальный файл `.env` текстовым редактором:

```dotenv
OPENAI_API_KEY=ваш_настоящий_ключ
OPENAI_MODEL=gpt-5.4-mini-2026-03-17
OPENAI_REASONING_EFFORT=low
COOKIE_SECURE=false
ALLOWED_EMAILS=
```

4. Перезапустите Python-сервер. Для Compose после изменения `.env`: `docker compose up -d --force-recreate`.
5. На странице «Настройки» отобразится выбранная модель и наличие ключа. Реальная доступность проверяется первым созданием поста. У результата должна появиться пометка «ИИ-редактура».

Не вставляйте ключ в посты или поле образцов. `.env` исключён из Git. Если выбрана старая модель без reasoning, например `gpt-4.1-mini`, задайте `OPENAI_REASONING_EFFORT=` (пустое значение).

## 4. Создать аккаунт

Откройте вкладку «Регистрация», укажите имя, email и пароль не короче 10 символов. Подтверждение по почте не требуется. У каждого пользователя свои настройки, диалог и файлы. Тестовых аккаунтов и общих паролей в проекте нет.

Когда будет список пользователей, можно записать их email в `ALLOWED_EMAILS` через запятую и перезапустить сервер. Это ограничивает новые регистрации, но не подтверждает владение адресом. Уже созданные аккаунты сохраняются.

## 5. Получить первый пост

1. В «Настройках» выберите источники, количество новостей и научные темы. Пустой выбор тем означает «все темы». Сохраните настройки.
2. В «Диалоге с редакцией» выберите 7 дней, 30 дней или собственный период. Обе даты включены; учитывается дата публикации источника по Москве.
3. Нажмите «Создать пост». Статус появится в диалоге. Вкладку можно закрыть, но сервер должен продолжать работать.
4. После завершения скачайте **«Текст поста»** (`post.txt`) и **«Изображения»** (`photos.zip`). В ZIP находятся обложка, доступные фотографии и `sources-and-credits.txt`.
5. Проверьте факты, формулировки и права на изображения. Опубликуйте материалы вручную в ВК. Приложение само не размещает их на стене.

Если подходящих новостей нет, расширьте даты или уберите тематические фильтры. RSS не содержит полный архив изданий; доступное покрытие видно во вкладке «Источники новостей».

## 6. Настроить автоматическую неделю

В «Настройках» включите еженедельную подборку, выберите день и час по Москве и нажмите «Сохранить настройки». Ближайшее время появится на главной странице.

В указанный момент приложение подготовит один пост за 7 предыдущих полных дней и добавит два файла в диалог. Браузер может быть закрыт. Компьютер и сервер приложения должны работать; сон компьютера останавливает обработку. После простоя пропущенный запуск выполняется один раз за последние 7 полных дней.

Для постоянной работы используйте сервер с Docker или системным менеджером процессов. Внешний доступ требует HTTPS reverse proxy и `COOKIE_SECURE=true`; по умолчанию приложение доступно только на локальном компьютере.

## 7. Добавить сообщество ВК

В «Настройках» сохраните ссылку, название, правила текста и 2–3 образца постов. Цвет акцента применяется к обложке, текстовые образцы — при подключённом ИИ.

Сохранение ссылки не читает стену автоматически. Точный анализ текстов и фотографий конкретного сообщества и настройка его визуального оформления запланированы после получения ссылки.

## Если что-то пошло не так

| Что видно | Что сделать |
| --- | --- |
| «Нет связи с сервером» | Запустить сервер, проверить адрес и порт. |
| Вместо ИИ-текста получился дайджест | Проверить ключ, баланс, доступ к модели и `OPENAI_REASONING_EFFORT`. Прочитать журнал сервера. |
| «Предыдущая подборка ещё готовится» | Дождаться завершения; повторная отправка не нужна. |
| За выбранные даты ничего нет | Проверить покрытие RSS-архива, источники и темы. |
| В архиве только обложка | Фото не были доступны в RSS или не загрузились; объяснение есть в диалоге. |
| Генерация упала при создании обложки | Проверить установку кириллического шрифта и `FONT_PATH`. |
| Нельзя зарегистрировать email | Проверить `ALLOWED_EMAILS` и существующий аккаунт с этим адресом. |
| Забыт пароль | Автоматического восстановления пока нет; обратитесь к владельцу сервера. |

Локальные данные находятся в `data/`. Для резервной копии остановите сервер и скопируйте папку целиком. При Docker нужно сохранять том `sno-data`, а не локальную папку.
