# Инструкция: от установки до первого поста

## 1. Скачать проект

```sh
git clone https://github.com/GnomikNaPony/mini_sno.git
cd mini_sno
```

Для последующих обновлений используйте `git pull --ff-only`, если в папке нет собственных незакоммиченных изменений.

## 2. Установить Qwen через Ollama

Рекомендуемая модель — `qwen3.5:9b`, около 6,6 ГБ. Первый запуск потребует загрузки модели.

### macOS

```sh
brew install ollama
brew services start ollama
ollama pull qwen3.5:9b
```

Проверка:

```sh
ollama list
ollama run qwen3.5:9b "Ответь одним словом: работает?"
```

Ollama будет запускаться вместе со входом в систему. Остановить фоновую службу: `brew services stop ollama`.

### Linux

Установите Ollama по [официальной инструкции](https://ollama.com/download/linux), затем:

```sh
sudo systemctl enable --now ollama
ollama pull qwen3.5:9b
```

### Windows

Установите Ollama с [официальной страницы](https://ollama.com/download/windows). В PowerShell выполните:

```powershell
ollama pull qwen3.5:9b
ollama run qwen3.5:9b "Ответь одним словом: работает?"
```

Если 9B не помещается в память, временно укажите `OLLAMA_MODEL=qwen3.5:4b` в `.env` и загрузите `ollama pull qwen3.5:4b`. Качество текста может снизиться.

## 3. Запустить приложение

### macOS / Linux, Python 3.11+

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000 --workers 1 --no-proxy-headers
```

Откройте **http://127.0.0.1:8000**. Терминал должен оставаться работающим. Остановка — `Ctrl+C`, повторный запуск — последняя команда.

На Linux для кириллических обложек установите `fonts-dejavu-core`. На macOS приложение использует системный Arial.

### Windows, PowerShell

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Добавьте в `.env` строку `FONT_PATH=C:/Windows/Fonts/arial.ttf`, затем:

```powershell
.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 --workers 1 --no-proxy-headers
```

Windows-команды подготовлены для установки, автоматическая проверка проекта выполнена на macOS.

### Docker Compose

Ollama с моделью должен работать на основной системе. Контейнер запускает веб-приложение и обращается к нему через `host.docker.internal`.

```sh
cp .env.example .env
docker compose up -d --build
docker compose ps
```

Журналы: `docker compose logs --tail=100 app`. Обновление: `git pull --ff-only`, затем `docker compose up -d --build`. Остановка: `docker compose down`.

Данные хранятся в томе `sno-data`. Не выполняйте `docker compose down -v`, если хотите сохранить аккаунты и историю. На Linux Ollama может потребоваться слушать адрес, доступный контейнеру; задайте его по официальной документации Ollama и укажите `OLLAMA_BASE_URL_DOCKER` в `.env`.

## 4. Проверить настройки модели

Файл `.env` по умолчанию содержит:

```dotenv
AI_PROVIDER=ollama
OLLAMA_MODEL=qwen3.5:9b
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_NUM_CTX=8192
OLLAMA_TEMPERATURE=0.45
```

После изменения `.env` перезапустите приложение. В разделе «Настройки» должно появиться сообщение, что модель доступна. Если модель недоступна, пост всё равно будет создан как обычный дайджест.

Локальный режим не требует API-ключа. Новости и образцы стиля передаются только процессу Ollama на указанном адресе.

### Необязательный OpenAI API

Чтобы вернуться к платному провайдеру:

```dotenv
AI_PROVIDER=openai
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-5.4-mini-2026-03-17
OPENAI_REASONING_EFFORT=low
```

Не добавляйте настоящий ключ в Git. `.env` уже исключён из репозитория.

## 5. Создать аккаунт и первый пост

1. Откройте «Регистрация», укажите имя, email и пароль не короче 10 символов.
2. В «Настройках» выберите источники, количество новостей и темы. Пустой выбор тем означает все темы.
3. При желании добавьте название общества, правила текста и 2–3 примера постов. Сохраните настройки.
4. В «Диалоге с редакцией» выберите 7 дней, 30 дней или собственные даты и нажмите «Создать пост».
5. Дождитесь результата. Первый запрос после перезапуска может быть медленнее: Ollama загружает 6,6 ГБ модели в память.
6. Скачайте `post.txt` и `photos.zip`. В ZIP находятся обложка, доступные фотографии и `sources-and-credits.txt`.
7. Перед публикацией проверьте факты, формулировки и права на изображения. Приложение не публикует пост в ВК автоматически.

Обе даты периода включены; используется дата публикации источника по Москве. RSS не содержит полный архив. Доступный период показан во вкладке «Источники новостей».

## 6. Еженедельное расписание

В «Настройках» включите еженедельную подборку, выберите день и час по Москве и сохраните. Пост будет собран за 7 предыдущих полных дней и появится в диалоге.

Браузер можно закрыть. Компьютер, Ollama и сервер приложения должны работать; сон компьютера останавливает обработку. После простоя приложение один раз обработает последние 7 полных дней и назначит следующее время.

## 7. Пользователи и ВК

Чтобы ограничить новые регистрации, перечислите email через запятую:

```dotenv
ALLOWED_EMAILS=student1@university.ru,student2@university.ru
```

Это не подтверждает владение адресом. Восстановления пароля по почте пока нет.

Ссылка на сообщество ВК сохраняется в настройках как ориентир. Автоматическое чтение стены не реализовано. После получения ссылки нужно отдельно проанализировать тексты и фотографии и проверить Qwen на характерных примерах.

## Если что-то пошло не так

| Что видно | Что сделать |
| --- | --- |
| Модель недоступна | Выполнить `ollama list`, проверить наличие `qwen3.5:9b` и открыть `http://127.0.0.1:11434/api/tags`. |
| Вместо ИИ-текста получился дайджест | Проверить, что Ollama запущен, имя модели совпадает с `.env`, затем посмотреть журнал приложения. |
| Первый пост готовится долго | Дождаться загрузки модели в память; следующие запросы в течение 10 минут будут быстрее. |
| «Предыдущая подборка ещё готовится» | Дождаться завершения текущего задания. |
| За выбранные даты ничего нет | Расширить даты, убрать фильтры тем, проверить покрытие RSS. |
| В архиве только обложка | Фото отсутствовали в RSS или не загрузились; объяснение есть в диалоге. |
| Ошибка обложки | Проверить кириллический шрифт и `FONT_PATH`. |
| Нельзя зарегистрировать email | Проверить `ALLOWED_EMAILS` и существующий аккаунт. |

Локальные данные находятся в `data/`. Для резервной копии остановите приложение и скопируйте папку целиком. В Docker сохраняйте том `sno-data`.
